# Python Engineering

A collection of Python projects documenting my journey from learning the fundamentals of Python to building practical engineering applications.

This repository is part of my Electrical & Computer Engineering learning roadmap. The goal is to develop strong programming and software engineering skills that support future work in Digital Signal Processing (DSP), FPGA development, Embedded Systems, Computer Architecture, and engineering software development.


## Objectives

* Master Python programming fundamentals
* Build practical Object-Oriented Programming (OOP) skills
* Develop clean, modular, and maintainable code
* Learn scientific computing with NumPy and Matplotlib
* Apply Python to engineering and signal processing problems
* Build a portfolio of engineering-focused projects
