# Student Management System

A console-based Student Management System built with Python to practice **Object-Oriented Programming, file handling, CSV persistence, repositories, and service-layer architecture**.

## Features

* Student management

  * Add, update, search, and delete students
* Course management

  * Add, update, search, and delete courses
* Course offering management

  * Manage courses offered by semester and academic year
* Enrollment management

  * Enroll students, update enrollment status, and assign grades
* Reports

  * Student transcript
  * Student GPA
  * Course enrollment report
  * Department report
  * Student statistics

## Technologies

* Python
* Object-Oriented Programming
* CSV File Handling
* Python `Enum`
* Repository and Service-layer architecture

## Data Storage

The system uses CSV files for persistent storage instead of a database.

## Purpose

This project was built as a practical Python OOP project to apply concepts such as **classes, inheritance/encapsulation, enums, validation, exception handling, file handling, repositories, and business logic** in a larger application.
