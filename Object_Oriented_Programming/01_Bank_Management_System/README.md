# Bank Management System

A console-based Bank Management System developed in Python using Object-Oriented Programming principles.

This project is part of my **Python Engineering** learning roadmap and focuses on applying object-oriented design, custom exceptions, file handling, and CSV data storage to build a realistic banking application.


## Features

### Customer Management

* Create customers
* View all customers
* Search customers by ID
* Update customer information
* Delete customers

### Account Management

* Create bank accounts
* View all accounts
* Search accounts
* Close accounts

### Transactions

* Deposit money
* Withdraw money
* Transfer money between accounts

### Reports

* View all customers
* View all accounts
* Display total number of customers
* Display total balance across all accounts
