# Matrix Analysis

A NumPy-based command-line application for analyzing and performing operations on matrices.

## Features

* Matrix properties: shape, dimensions, size, and data type
* Determinant, inverse, and rank
* Eigenvalues and eigenvectors
* Matrix transpose
* Matrix addition and subtraction
* Scalar multiplication
* Matrix multiplication
* Solving systems of linear equations

## Technologies

* Python
* NumPy

## Run

```bash
python main.py
```
